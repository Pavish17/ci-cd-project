# CI/CD Project

## Project Name

CI/CD Pipeline Automation using Tekton

## Description

This project demonstrates Continuous Integration and Continuous Delivery using Tekton, OpenShift, and GitHub.

## Project Details

The pipeline performs the following steps:

- Cleanup
- Git Clone
- Linting using ESLint
- Unit Testing using Jest
- Build using Buildah
- Deployment using OpenShift

## Technologies Used

- GitHub
- GitHub Actions
- Tekton
- OpenShift
- Node.js
- ESLint
- Jest
- Buildah
